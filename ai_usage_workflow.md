# Goal: Design the world's most powerful AI usage workflow to maximize the quality of AI outputs and minimize the cost of AI usage.

## Methodology
- Establish the ask/ want/ need properly.
    - Use a generic AI Agent to detail and scope out the ask/ want/ need properly iteratively.
- Generate the plan to achieve the ask/ want/ need.
    - ** Implementation Plan **: Use the primary specialist AI Agent to generate the plan file `implementation_plan.md` to achieve the ask/ want/ need. Get it reviewed by a peer (another powerful AI model in another specialist AI Agent (same specialization)). Iterate if required.
- Plan the execution.
    - ** Task List **: Use the primary specialist AI Agent to break down the ask/ want/ need into smaller tasks with clear input and output specifications . Get it reviewed by a peer (another powerful AI model in another specialist AI Agent (same specialization)). Iterate if required.
    - ** Agent Orchestration **: Use the primary specialist AI Agent to recommend task allocation to a team of specialist AI agents.
- Execute the plan.
    - Use the primary specialist AI Agent to coordinate work progress across all the team of AI Agents and collate the outputs into a finished output.
- Review and Refine the output.
    - Get the output reviewed by a peer (another powerful AI model in another specialist AI Agent (same specialization)).
    - Pass feedback to the secondary agents.
    - Secondary Agents incorporate the feedback and produce an updated output.
    - Primary Agent collates the updated outputs from all the secondary agents and produces the final output.
- Learn from experience.
    - Secondary Agents learn from this feedback to improve their performance in the future.
